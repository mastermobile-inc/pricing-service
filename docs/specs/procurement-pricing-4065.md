# Назначение

№4065 — вкладка «Ценообразование» приложения закупок. План реализации утверждён
пользователем 2026-09-19. Статус review сохраняется до технической проверки
пересчёта и оформления доказательств допуска к записи.

# Change Summary / Spec Delta

Было: нет единого анализа и пакетного утверждения продажных цен.
Станет: индивидуальная бронза/платина, аналитика, утверждение закупщиком,
файловый коннектор и результат проведённой установки цен. Остальные цены скрыты.
Не меняются формула рентабельности закупок и правила пересчёта зависимых цен 1С.

# Scope / Out of Scope

Входит таблица каталога, произвольный период, фильтры рентабельности/брака «от/до»,
динамика, графики двух цен, факты и прогноз, прошлый год, конкуренты, личные пресеты,
XLSX/CSV всех отфильтрованных строк, проекты и пакетное утверждение.
Массовые наценки, одинаковая цена семейства, новая формула зависимых цен исключены.

# Source of Truth

1С — фактические продажи, возвраты, себестоимость и цены. Каталог/принятые
сопоставления конкурентов — существующие модели сервиса. Пакет — неизменяемое
решение закупщика. Неполные данные не подменяются нулями.
Проверены observed source от 2026-09-12, модуль документа
УстановкаЦенНоменклатуры: проведение дополняет зависимые цены с ненулевой наценкой.
Полная цепочка бронза/платина и актуальная runtime-проверка пока не доказаны.

# API / Data Contracts

API внутри /procurement-order-formation/pricing: таблица, история, экспорт,
пресеты и пакеты с утверждением. Автор определяется проверенной сессией Bitrix.
Отдельный файловый контракт procurement_pricing.v1: message_id, idempotency_key,
автор, время, строки с кодом 1С, типом bronze/platinum, старой и новой ценой.
Пустое изменение не записывает ноль. Один пакет — один документ, атомарно.
Результат: applied/error/conflict, ссылка/номер документа и фактические цены.
Применение признаётся после проведения и readback. Повтор не создаёт документ.

# Acceptance Criteria

- [ ] Только бронза и платина, отдельная цена каждой карточки.
- [ ] Метрики совпадают с 1С за выбранный период, отсутствие данных явно.
- [ ] Прогноз: среднее по завершённым календарным дням, включая нули;
      неполная история блокирует прогноз; прошлый год отдельно.
- [ ] Фильтры, пресеты, конкуренты, графики и полный экспорт работают.
- [ ] Пакет неизменяем после утверждения; чужие изменения дают конфликт.
- [ ] Повторная доставка и потеря ответа не дублируют установку.
- [ ] Проверены зависимые цены и откат транзакции на тестовой 8.2.19.130.

# Tests

Адресные pytest, UI-тесты и браузерная проверка; Ruff, Black, pytest, OpenAPI,
validators. Для 1С — статические проверки и live-матрица в Ekama_Test_Integration:
бронза, платина, обе, повтор, сбой, конфликт, пересчёт и readback.

# Rollout

Пока флаг передачи выключен. Сначала тестовая база, затем публикация приложения
с выключенной записью. Production-запись требует отдельного разрешения.
При ошибке остановить отправки, сверить операции; восстановление применённых цен
только корректирующим документом. Срок 23 сентября не является оценкой разработки.
