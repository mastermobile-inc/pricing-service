# Решение владельца: только бронза и платина (2026-09-19)

Действующий периметр №4065 — установка только бронзы и платины выбранных карточек.
Успех: один проведённый документ, фактические значения совпадают с утверждёнными;
незаполненный тип сохраняет прежнюю цену. Остальные типы — отдельный вопрос.
Обычное проведение документа 1С сохраняется; дополнительный расчёт других типов
не запускается, его результат не проверяется и не блокирует приёмку №4065.

**ОТМЕНЕНО (2026-09-19, уточнение владельца):** прежние требования подтвердить
полную цепочку серебра/золота/розницы, искать отдельную команду пересчёта,
проверять dependentPricesVerified и включать PROCUREMENT_PRICING_RULES_VERIFIED.
Исторические наблюдения ниже сохранены, но не являются текущими блокерами.
Разрешение передачи остаётся отдельным флагом PROCUREMENT_PRICING_APPLY_ENABLED;
он выключен до завершения испытаний и допуска соответствующего контура.

# Change Summary / Spec Delta

Было: нет единого анализа и пакетного утверждения продажных цен.
Станет: индивидуальная бронза/платина, аналитика, утверждение закупщиком,
файловый коннектор и результат проведённой установки цен. Остальные цены скрыты.
Не меняются формула рентабельности закупок и правила пересчёта зависимых цен 1С.

# Scope / Out of Scope

Входит таблица каталога, произвольный период, фильтры рентабельности/брака «от/до»,
динамика, графики двух цен, факты и прогноз, прошлый год, конкуренты, личные пресеты,
XLSX/CSV всех отфильтрованных строк, проекты и пакетное утверждение.
Массовые наценки, одинаковая цена семейства, новая формула зависимых цен исключены.

# Source of Truth

1С — фактические продажи, возвраты, себестоимость и цены. Каталог/принятые
сопоставления конкурентов — существующие модели сервиса. Пакет — неизменяемое
решение закупщика. Неполные данные не подменяются нулями.
Проверены observed source от 2026-09-12, модуль документа
УстановкаЦенНоменклатуры: проведение дополняет зависимые цены с ненулевой наценкой.
Полная цепочка бронза/платина и актуальная runtime-проверка пока не доказаны.

# API / Data Contracts

API внутри /procurement-order-formation/pricing: таблица, история, экспорт,
пресеты и пакеты с утверждением. Автор определяется проверенной сессией Bitrix.
Отдельный файловый контракт procurement_pricing.v1: message_id, idempotency_key,
автор, время, строки с кодом 1С, типом bronze/platinum, старой и новой ценой.
Пустое изменение не записывает ноль. Один пакет — один документ, атомарно.
Результат: applied/error/conflict, ссылка/номер документа и фактические цены.
Применение признаётся после проведения и readback. Повтор не создаёт документ.

По умолчанию после фильтрации цены читаются только для видимой страницы.

вся витрина до оптимизации страниц — 167 с. После оптимизации проверены первая страница за 13,55 с и следующая за 0,58 с.
После замены больших IN-списков общим запросом цены 29 352 карточек прочитаны за 3,27 с.
40 значений сверены с адресным запросом на том же моменте и совпали.
Первая страница сортировки по бронзе — 18,34 с с холодной аналитикой;
полный набор для экспорта — 29 352 строки за 3,88 с с прогретой аналитикой.

## Независимая сверка и исправление — 2026-09-19

Native-запросы 1С 8.2.19.130 сопоставлены с фактической `_period` за август 2026
в Ekama_Test_Integration. Выявлено 2838 расхождений сумм продаж: SQL суммировал
`_Fld4982` (Цена), а не `_Fld4979` (Сумма строки). Соответствие подтверждено
`ПолучитьСтруктуруХраненияБазыДанных`; запрос вкладки исправлен. Регрессионный
тест проверяет две единицы со скидкой: сумма строки 180, а не цена 100/сумма 200.

Повторная сверка: 13132 карточки продаж (количество/сумма), 5665 возвратов
(сумма/количество по действующим признакам брака), 13217 себестоимости —
**0 расхождений**. Пустые ссылки номенклатуры не являются карточками и исключены
с обеих сторон. Это сверка с тестовой копией, не приёмка отчёта production.
Распознавание причин возврата совпало с действующим правилом закупок; отдельная
бизнес-проверка подтверждённости брака остаётся открытой.

Соседний существующий procurement_order_metrics.py также использует _Fld4982;
его исправление и отдельная регрессия не входят в эту правку вкладки №4065.

Кандидат коннектора прошёл через EPF одновременный дубликат, конкурирующие пакеты
и отказ после native-проведения с откатом. Native-сборка проверена; установка
обновления в Integration ожидает свободной базы. Полная приёмка и production
не завершены.
